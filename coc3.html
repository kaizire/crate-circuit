The lab PC runs Proxmox VE. Windows Server, AD, DHCP, and DNS install only inside the virtual machine. Students open the Proxmox console from a phone on school Wi‑Fi.

How you join

  1. Join school Wi‑Fi.
  2. Open kaizire.github.io/crate-circuit/coc3.html
  3. Tap Open Proxmox lab. If the phone warns about a certificate, tap Advanced → Continue.
  4. Sign in with the student account the teacher gives you. Open VM COC3-SERVER → Console.

Teacher · install Proxmox VE

Host the disk here

  1. Download the ISO from proxmox.com/en/downloads (Proxmox VE 9). Write it to a USB with Rufus.
  2. Boot a spare lab PC from that USB and install Proxmox. Set a management IP on school LAN (example 192.168.1.20).
  3. On another computer open https://192.168.1.20:8006 (use your IP). Login root.
  4. Create VM 100 named COC3-SERVER (4 GB RAM, UEFI or SeaBIOS, SATA disk). Create VM 101 named COC3-CLIENT.
  5. To import a VMware disk, copy the .vmdk onto Proxmox then run: qm disk import 100 /root/COC3-SERVER.vmdk local-lvm --format qcow2 Attach the unused disk as SATA, set boot order, start the VM.
  6. Or skip the VMware disk: attach a Windows Server evaluation ISO in Proxmox and install inside VM 100.
  7. Datacenter → Permissions → Users: add student@pve. On VM 100 give that user role PVEVMUser (console only, not root).
  8. Paste the Proxmox address below (example 192.168.1.20) and tap Share with class.
