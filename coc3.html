Student logon

Open the VM
as a student.

You do not need a teacher account or the staff password. This opens Remote Desktop into the Windows VM. VMware Workstation stays on the school PC.

Log on as student / crate-lab. Never use the teacher or admin account.

Join school Wi‑Fi, type the VM address if it is empty, then tap Open the VM.

Remote Desktop app

On Android or iPhone install Microsoft Remote Desktop, then tap Open the VM and allow it. Open the downloaded COC3-SERVER.rdp file if the app does not start.

Students only

How you enter

  1. Join school Wi‑Fi. Install Microsoft Remote Desktop from the Play Store or App Store.
  2. Type the VM address (example 192.168.1.50) if it is not already filled.
  3. Tap Open the VM. Allow Remote Desktop. If needed, open the COC3-SERVER.rdp download.
  4. Username student. Password crate-lab. Not the teacher login.
  5. You are inside the Windows VM. Installers stay there, not on your phone.
