Students · cellphone

How you enter the server

  1. Join school Wi‑Fi.
  2. Open this page: kaizire.github.io/crate-circuit/coc3.html
  3. Tap Open Azure lab.
  4. Sign in with the lab Microsoft account (not your personal email unless the teacher says so).
  5. Open virtual machine COC3-SERVER → Connect → Bastion → RDP → Connect.
  6. The Windows desktop is the lab. Do not install Windows Server on your phone.

Teacher · create Azure

1. Sign up

  1. Go to Azure for Students with a school email. If that is rejected, use the free Azure account.
  2. Open portal.azure.com.

2. Create COC3-SERVER

  1. Search Virtual machines → Create → Azure virtual machine.
  2. Resource group: coc3-lab (create new).
  3. Name: COC3-SERVER.
  4. Region: Southeast Asia.
  5. Image: Windows Server 2022 Datacenter.
  6. Size: Standard B2s (2 vCPU, 4 GB).
  7. Username: coc3admin. Save the password.
  8. Public inbound ports: None. Do not open RDP to the internet.
  9. Review + create → Create. Wait until it is Running.

3. Open it in the browser

  1. Click the VM → Connect → Bastion.
  2. Use Developer (free) if the region offers it.
  3. Protocol RDP, username coc3admin, your password → Connect.
  4. A Windows desktop opens in Chrome or Edge. That is the virtual machine.

4. Install COC 3 inside Azure only

  1. In that desktop, install Active Directory Domain Services, DNS, DHCP, and File Services.
  2. Give the class one lab Microsoft account. Do not share your personal Microsoft password.
  3. After class, open the VM and click Stop so credits last. Start it before the next session.
