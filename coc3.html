COC/3

Phone + VM lab

Use your phone.
Install in the VM.

Open this page on a cellphone. Windows Server, Active Directory, DHCP, and DNS install only inside the virtual machine on the lab PC — never on a phone and never on the host PC.

Installers stay in COC3-SERVER and COC3-CLIENT. Students do not download or run setup files on their phones.

Students · cellphone

How you join

  1. Join the school Wi‑Fi.
  2. Open this page: kaizire.github.io/crate-circuit/coc3.html
  3. Install Microsoft Remote Desktop from the App Store or Google Play (this app only views the VM; it does not install Windows).
  4. Ask the teacher for the VM address (example: 192.168.1.50) and the student logon.
  5. Tap Add PC → enter that address → connect. You are now inside the virtual machine.

Lab PC · virtual machine

Where every installer goes

  1. On the lab PC, open VMware Workstation (or VirtualBox). Do not run Windows Server setup on the PC desktop.
  2. Use two VMs: COC3-SERVER and COC3-CLIENT. Create them in VMware or run the setup script on the lab PC only.
  3. Attach the Microsoft evaluation ISO to the VM DVD drive. Start the VM and install Windows in the VM window.
  4. On COC3-SERVER only: install AD DS, DNS, DHCP, and File Services. Turn on Remote Desktop. Set the network to Bridged so phones on Wi‑Fi can reach it. Write the VM IP on the board.
  5. On COC3-CLIENT only: join the domain and test. No roles on the host PC.
